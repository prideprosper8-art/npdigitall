## 🔔 Setting Up WhatsApp Notifications

While Netlify Forms doesn't natively send to WhatsApp, you can use Zapier or Make.com:

### Option 1: Zapier (Easiest)

1. Create free Zapier account: https://zapier.com
2. Create new Zap:
   - **Trigger:** Netlify Form Submission
   - **Action:** Send WhatsApp message (via WhatsApp Business or CallMeBot)
3. Connect your Netlify account
4. Select the "contact" form
5. Configure WhatsApp action
6. Test and activate!

### Option 2: Make.com (More powerful)

1. Create free Make.com account: https://make.com
2. Create new scenario:
   - **Trigger:** Webhook (get webhook URL)
   - **Action:** Send WhatsApp message
3. Add webhook in Netlify:
   - Settings → Forms → Form notifications
   - Add notification → Outgoing webhook
   - Paste Make.com webhook URL
4. Test and activate!

## 🛡️ Spam Protection

Netlify Forms includes built-in spam protection:

✅ **Honeypot field** - Hidden field that bots fill out
✅ **reCAPTCHA** (optional) - Can be added if needed
✅ **Rate limiting** - Netlify automatically limits submissions

### To Add reCAPTCHA (Optional):

1. Get reCAPTCHA keys from Google: https://www.google.com/recaptcha
2. Add to form in HTML:
   ```html
   <div data-netlify-recaptcha="true"></div>
   ```
3. Netlify handles the rest automatically!

## 🚨 Troubleshooting

### Form not appearing in dashboard?

**Solution:**
1. Make sure you deployed after adding `data-netlify="true"`
2. Forms must be in the deployed HTML (not generated by JS)
3. Wait a few minutes after first deployment
4. Try submitting a test form

### Not receiving email notifications?

**Check:**
1. Email notification is set up in dashboard
2. Check spam/junk folder
3. Verify email address is correct
4. Test with a form submission

### Submissions showing as spam?

**Options:**
1. Review spam submissions in dashboard
2. Mark legitimate ones as "Not spam"
3. Add reCAPTCHA if needed
4. Adjust spam sensitivity in settings
