# ✅ Quick Form Setup Checklist

## Do These Steps Now (5 minutes)

### Step 1: Login to Netlify
Go to: https://app.netlify.com/sites/npdigitall

### Step 2: Check Form Detection
- [ ] Click **"Forms"** in the top menu
- [ ] Confirm you see **"contact"** form listed
- [ ] If not visible, wait 2-3 minutes and refresh

### Step 3: Add Email Notification
- [ ] Click **"Settings"** → **"Forms"** → **"Form notifications"**
- [ ] Click **"Add notification"**
- [ ] Choose **"Email notification"**
- [ ] Set email to: **npdigitalinfo@gmail.com, contact@npdigitall.com**
  - Or create two separate notifications (one for each email)
- [ ] Select form: **contact**
- [ ] Click **"Save"**

### Step 4: Test It
- [ ] Go to https://npdigitall.netlify.app/#contact
- [ ] Fill in:
  - Name: Test User
  - Email: your-test-email@example.com
  - Message: This is a test submission
- [ ] Click **"Send project enquiry"**
- [ ] Should see success message
- [ ] Check **npdigitalinfo@gmail.com** for notification email

### Step 5: Verify in Dashboard
- [ ] Go back to Netlify → Forms → contact
- [ ] See your test submission listed
- [ ] Delete the test submission if desired
