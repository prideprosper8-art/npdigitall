# NP Digital — Company Website

Premium marketing site + enquiry API for **NP Digital** (Harare, Zimbabwe).
Tagline: *Ideas | Systems | Solutions | Beyond*.

## Stack

- **Vite + TypeScript** — multi-page app (`index`, `projects`, `privacy`, `terms`, `404`)
- **Three.js** — lazy-loaded interactive 3D technology core with CSS fallback,
  reduced-motion and no-WebGL handling
- **Express + Zod** — production server, validated enquiry API, CRM-ready adapter
- **sharp** — build-time logo derivative generation (watermark-free crop, favicon, OG image)

## Commands

```bash
npm install            # install dependencies
npm run dev            # Vite dev server (frontend only)
npm run build          # generate images + build frontend + typecheck
npm run server:build   # compile the Express server to dist-server/
npm start              # serve dist/ + API (NODE_ENV=production, default :8787)
npm run serve          # same, without NODE_ENV preset
```

## Enquiry API

`POST /api/inquiries` — JSON `{ name, email, service?, message }`

- Zod-validated server-side; friendly field errors returned as `{ ok:false, error }`
- In-memory sliding-window rate limit + optional `ENQUIRY_TOKEN` shared-secret check
- Persisted to `.data/inquiries.ndjson`; swap `persistInquiry` in `server/index.ts`
  for PostgreSQL/CRM (HubSpot, Zoho, etc.) — keys live in env vars only, never frontend

`GET /api/health` — liveness probe.

## Environment variables

| Variable        | Purpose                                        |
|-----------------|------------------------------------------------|
| `PORT`          | Server port (default `8787`)                   |
| `DATA_DIR`      | Enquiry storage directory (default `.data`)    |
| `ENQUIRY_TOKEN` | Optional shared secret for write access        |
| `TRUST_PROXY`   | Set when running behind a reverse proxy        |

## Deployment notes

- Any Node host works: `npm run build && npm run server:build && npm start`
- Static-only hosts (e.g. Netlify) can serve `dist/` directly, but then point the
  form at a hosted endpoint instead of the local API
- `public/sitemap.xml` and `public/robots.txt` reference `https://www.npdigital.in`
- Logo assets are regenerated by `scripts/prepare-images.mjs`; keep the original
  `public/assets/np-digital-logo.jpg` untouched as the brand master
